# IT313 Student Roster Card Renderer

## Problem
Create a React Native screen that displays enrolled students
using reusable cards and JSX.

## Components
- StudentCard: Displays the student's name, course, units,
  and Full Load label when applicable.
- StudentRoster: Stores the student data, calculates the total
  number of students, and renders cards using map().

## Concepts Used
- Functional components
- Props and destructuring
- JSX expressions
- Conditional rendering using &&
- List rendering using map()
- Stable keys using student IDs
- useState for reversing the roster and testing keys

## How to Run
1. Install Node.js.
2. Create an Expo project.
3. Replace App.js with the provided code.
4. Run:

   npx expo start

5. Open the app using Expo Go or an emulator.
